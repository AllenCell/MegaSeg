# Benchmark Visualization Plots — Design

**Date:** 2026-02-19
**Status:** Approved

## Overview

Add a `plot` subcommand to `scripts/evaluate_benchmark.py` that generates 6 publication-quality visualization plots from the computed benchmark metrics. Plots are generated for all 5 metrics (dice, iou, precision, recall, accuracy) in both PDF (paper/vector) and PNG (300dpi, presentations) formats.

## Decisions

- **Approach:** seaborn + matplotlib hybrid. Seaborn for structure (heatmaps, bar charts), matplotlib for fine-tuning.
- **Output formats:** PDF (vector, paper) + PNG (300dpi, presentations) for every plot.
- **Metrics:** All 5 metrics generated by default; `--metric` flag to restrict to one.
- **Integration:** New `plot` subcommand in existing evaluate_benchmark.py (alongside `compute` and `report`).
- **Data source:** `per_sample_metrics.csv` is the single source for all plots — each plot function filters/aggregates as needed.

## CLI Interface

```bash
# Generate all plots for all metrics
PROJECT_ROOT=$PWD python scripts/evaluate_benchmark.py plot --dtype uint8

# Single metric
PROJECT_ROOT=$PWD python scripts/evaluate_benchmark.py plot --dtype uint8 --metric dice

# Custom output directory
PROJECT_ROOT=$PWD python scripts/evaluate_benchmark.py plot --dtype uint8 --outdir results/uint8/figures
```

## Output Structure

```
results/{dtype}/figures/
  {metric}/
    cross_eval_heatmap.{pdf,png}
    individual_vs_megaseg.{pdf,png}
    backbone_comparison.{pdf,png}
    delta_improvement.{pdf,png}
    test_new_generalization.{pdf,png}
    summary_overview.{pdf,png}
```

Total: 60 files (6 plots × 5 metrics × 2 formats).

## Plot Specifications

### Plot 1: Cross-Eval Heatmap

- **Data:** Filter `eval_type == "cross_eval"` from per_sample_metrics, pivot to 14×14 matrix (model_struct × test_struct).
- **Layout:** Square heatmap, row = "Trained on", col = "Tested on".
- **Color:** Sequential colormap (viridis or RdYlGn), vmin=0, vmax=1.
- **Annotations:** Metric values in each cell (2 decimal places), diagonal highlighted.
- **Size:** ~10×9 inches.

### Plot 2: Individual vs MegaSeg Bar Chart

- **Data:** Filter `eval_type in (individual, megaseg)`, group by test_struct and backbone.
- **Layout:** Grouped bars — 14 structures on x-axis, 5 bars per structure (1 individual + 4 MegaSeg backbones).
- **Colors:** Distinct per model type (individual=gray, dynunet=blue, attention_unet=orange, swin_unetr=green, unet=red).
- **Error bars:** ±1 std from per-sample variation.
- **Size:** ~14×6 inches.

### Plot 3: Backbone Comparison

- **Data:** Filter `eval_type == "megaseg"` only, group by test_struct and backbone.
- **Layout:** Grouped bars — 14 structures on x-axis, 4 bars per structure (one per backbone).
- **Size:** ~12×6 inches.

### Plot 4: Delta Improvement Chart

- **Data:** Compute (megaseg mean − individual mean) per structure, per backbone.
- **Layout:** Horizontal bar chart, sorted by delta magnitude (best improvement at top).
- **Colors:** Green for positive, red for negative deltas.
- **Annotations:** Delta value at end of each bar.
- **Sub-layout:** 2×2 grid, one subplot per backbone.
- **Size:** ~10×10 inches.

### Plot 5: test_new Generalization

- **Data:** Filter test_new eval types (individual_test_new + megaseg test_new).
- **Layout:** Grouped bars — novel structures on x-axis, bars for individual + 4 MegaSeg backbones.
- **Size:** ~10×6 inches.

### Plot 6: Summary Overview

- **Data:** Aggregate means across eval types from per_sample_metrics.
- **Layout:** Bar chart — x-axis = eval type categories (individual, 4 megaseg backbones, cross_eval_diagonal, cross_eval_off_diagonal).
- **Error bars:** ±1 std.
- **Reference line:** Horizontal line at individual mean.
- **Size:** ~8×5 inches.

## Code Architecture

### New functions added to evaluate_benchmark.py

```
setup_plot_style()                           # Configure seaborn/matplotlib defaults
save_figure(fig, outdir, name)               # Save as both .pdf and .png
plot_cross_eval_heatmap(df, metric, outdir)  # Plot 1
plot_individual_vs_megaseg(df, metric, outdir) # Plot 2
plot_backbone_comparison(df, metric, outdir) # Plot 3
plot_delta_improvement(df, metric, outdir)   # Plot 4
plot_test_new_generalization(df, metric, outdir) # Plot 5
plot_summary_overview(df, metric, outdir)    # Plot 6
cmd_plot(args)                               # Subcommand handler
```

### Data flow

1. `cmd_plot` reads `per_sample_metrics.csv` into a single DataFrame.
2. For each metric (all 5, or just the requested one):
   - Creates `results/{dtype}/figures/{metric}/` directory.
   - Calls all 6 plot functions with the full DataFrame + metric name + output dir.
   - Each function filters/aggregates, creates a figure, calls `save_figure`.

### Style configuration

Shared `setup_plot_style()` sets:
- `sns.set_theme(style="whitegrid", font_scale=1.2)`
- Sans-serif font family, 300 DPI, tight bounding box
- Consistent color palette as module-level dict

### Error handling

- Missing `per_sample_metrics.csv` → helpful message pointing to `compute` subcommand.
- Missing data for a specific plot (e.g., no test_new results) → skip with warning, don't crash.
